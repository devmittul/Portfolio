Portfolio Website Versions

This portfolio website has multiple versions, each serving a different purpose. Below is an explanation of each version and when to use it.

index.html - Main Version

This is the primary version of the portfolio with full features, modern styling, and animations. Use this version for normal viewing and sharing with others.

Features: Full animations, modern glass-effect UI, complete responsive design

View Main Version

basic.html - Simplified Version

A simplified version of the portfolio with basic styling. This version may load faster on older devices or slower connections.

Features: Simplified styling, faster loading, core content

View Basic Version

debug.html - Debug Version

A special version for debugging purposes. It loads the main site in an iframe with all animations disabled, making it easier to inspect elements and troubleshoot issues.

Features: Animations disabled, elements fully visible, debugging-friendly

View Debug Version

Launch Scripts

The following batch files are available to launch different versions of the website:

  • launch-website.bat - Opens the main version (index.html)
  • launch-index.bat - Also opens the main version (index.html)
  • view-website.bat - Opens the main version (index.html)
  • view-website-debug.bat - Creates and opens the debug version
